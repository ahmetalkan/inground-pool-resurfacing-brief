# In-Ground Pool Resurfacing Brief

A homeowner reference for recognizing when an in-ground concrete pool shell needs resurfacing, comparing marcite plaster, quartz, and pebble finishes, handling acid-wash chemicals safely, and running startup brushing and water balance with WHO, MedlinePlus, and OSHA references.

This is a free, standalone mini-resource published on GitHub Pages:

- Homepage — in-ground pool resurfacing readiness brief: `https://ahmetalkan.github.io/inground-pool-resurfacing-brief/`
- Subpage — separating surface scaling/stains from delamination and shell wear: `https://ahmetalkan.github.io/inground-pool-resurfacing-brief/signs-a-pool-needs-resurfacing.html`
- Subpage — comparing white plaster, quartz aggregate, and exposed pebble finishes: `https://ahmetalkan.github.io/inground-pool-resurfacing-brief/plaster-quartz-pebble-finishes.html`
- Subpage — curing new plaster during the first 28 days after refill: `https://ahmetalkan.github.io/inground-pool-resurfacing-brief/startup-water-chemistry-notes.html`

It cites public pages on [poolresurfacingguide.com](https://poolresurfacingguide.com/) and official reference sources listed at the bottom of each page. Nothing here is a substitute for advice from a qualified professional.
